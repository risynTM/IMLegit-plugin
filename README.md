# IMLegit-plugin
This is supposed/going to be a plugin that can verify a run as "legit" (aka. not cheated and not using stuff like pause buffer abuse) by analzing various data points such as:
- Inputs over multiple attempts
- real time timestamps for race start, checkpoints and finishes
- pause events
- installed & active plugins

That (and maybe more) data will be sent to a server for processing (never trust the client and all that) and if something suspicious is detected it will be sent to human review. Will this be sustainable? we'll see xdd
